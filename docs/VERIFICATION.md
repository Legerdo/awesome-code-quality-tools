# 검사 범위와 결과 기록

[README](../README.md) / [에이전트 안내](AGENT-GUIDE.md)

## 자동으로 확인하는 것

| 검사 | 확인하는 내용 | 확인하지 않는 내용 |
| --- | --- | --- |
| 목록과 정책 | ID, 참조, 지원 언어, 라이선스 분류가 서로 맞는지 확인한다. | 법적 적합성을 인증하지 않는다. |
| 문서 재생성 | JSON과 Markdown 표가 일치하는지 비교한다. | 외부 도구의 기능을 실행해 보지 않는다. |
| 내부 링크 | 파일과 명시적으로 지정한 앵커가 있는지 확인한다. | 외부 사이트 접속 여부를 검사하지 않는다. |
| 실패 사례 | 잘못된 라이선스나 제외 도구를 넣었을 때 검사가 실패하는지 확인한다. | 모든 사실 오류나 어색한 문장을 찾지는 못한다. |
| 스킬 파일 | 이 저장소가 쓰는 단순한 헤더 필드, 이름, 길이, 문서 연결을 확인한다. | Agent Skills 규격 전체의 인증이나 에이전트 행동 평가가 아니다. |
| JSON 조회 | 필요한 항목과 근거가 함께 출력되는지, 잘못된 ID를 거부하는지 확인한다. | 대상 프로젝트를 스캔하거나 분석기를 실행하지 않는다. |

수록된 분석기의 실제 실행, 성능, 정확도, 오탐률을 검증한 것은 아니다. 모든 배포 바이너리, 간접 의존성, 룰팩, 플러그인의 라이선스를 전수 검토한 것도 아니다.

## 프로젝트에 적용할 때

[검사 기록 양식](templates/QUALITY-CHECK.md)에 OS, 도구 버전, 명령, 작업 디렉터리, 검사 범위, 기대 결과, 실제 진단과 원본 로그를 남긴다.

실행 상태와 합격 여부는 구분한다. `execution_status`는 `succeeded`, `failed`, `skipped`, `timeout`, `partial` 중 하나다. `policy_status`는 `pass`, `fail`, `not_evaluated` 중 하나다. 분석기가 정상적으로 위반을 찾으면 실행은 성공했지만 품질 기준에는 실패할 수 있다.

도구 미설치, 분석기 오류, 시간 초과, 일부 파일 누락을 통과로 기록하지 않는다. 0이 아닌 종료 코드도 진단 발견 때문인지 분석기 오류 때문인지 확인한다. JSON이나 SARIF 형식과 종료 코드의 의미는 사용할 버전의 문서를 기준으로 한다.

## 시험할 사례

| 종류 | 예시 |
| --- | --- |
| 찾아야 하는 문제 | 미사용 직접 의존성, 금지한 계층의 import, 순환 참조, 의도적으로 넣은 오류 패턴 |
| 보존해야 하는 사용 경로 | Unreal 리플렉션과 Blueprint 참조, Unity 직렬화와 씬 콜백, Godot 시그널, 프레임워크 등록과 플러그인 진입점 |
| 검사 실패 | 잘못된 설정, 파싱 오류, 도구 누락, 시간 초과, 일부 파일만 분석한 결과 |

미사용 진단만으로 삭제하지 않는다. 실제 대상의 빌드, 관련 테스트, 엔진 에셋 검사로 사용 경로를 확인한다. 그래프에 연결이 없다는 이유만으로 실행 중에도 쓰이지 않는다고 단정하지 않는다.

## 저장소 검사 명령

Python 3.13 표준 라이브러리만 사용한다. 저장소 루트에서 실행한다.

```powershell
python scripts/catalog.py --check
python scripts/check_skills.py
python -m unittest discover -s tests -v
git diff --check
```

문서 원본을 바꿨다면 먼저 `python scripts/catalog.py --write`로 생성 파일을 갱신한다. CI는 Windows와 Ubuntu에서 같은 Python 검사를 실행한다. CI 설정만으로 병합이 차단되지는 않으며 브랜치 보호는 별도 설정이다.

## 검사 기준을 바꿀 때

정책이나 검사 코드를 수정하는 이유와 영향을 기록한다. 기존에 거부하던 입력이 새로 허용되는지 확인하고, 정상 사례와 실패 사례를 함께 시험한다.

이번 에이전트 자료 추가에서는 기존 목록 검사를 유지하고 스킬 파일과 읽기 전용 조회 명령의 테스트를 추가했다. 문장 자연스러움이나 에이전트의 자동 스킬 발견을 통과 항목으로 추가한 것은 아니다.
